# Useful Snippets
A collection of reusable and practical code snippets from my past projects, mainly focused on ESP32, AI models, cloud integration, and automation. Please note that all snippets have been salvaged and generalized; some may still be too specific to particular projects I worked on.

## Contents
- [AI/](./AI) – Snippets for AI models and decision-making.
- [Automation/](./Automation) – Code for controlling LEDs, buzzer, and other outputs.
- [Dashboard/](./Dashboard) – Web dashboard, charts, and data display examples
- Cloud/ – Backend examples, API calls, logging to cloud.
- [Data/](./Data) – Logging, CSV handling, and sensor data processing.
- [Security/](./Security)
- Misc/ – Other miscellaneous snippets for specific purposes.

## Usage
Each folder contains code snippets related to that topic or language. Feel free to browse, copy, and configure as needed.
