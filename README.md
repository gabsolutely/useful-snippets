# Useful Snippets
A collection of reusable and practical code snippets from my past projects, mainly focused on ESP32, AI models, cloud integration, and automation.

## Contents
- AI/ – Snippets for AI models and decision-making.
- Automation/ – Code for controlling LEDs, buzzer, and other outputs.
- Dashboard/ – Web dashboard, charts, and data display examples
- Cloud/ – Backend examples, API calls, logging to cloud.
- Data/ – Logging, CSV handling, and sensor data processing.

## Usage
Each folder contains code snippets related to that topic or language. Feel free to browse, copy, and configure as needed.
